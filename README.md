# Curso de NumPy - Arrays, indexación y ejercicios prácticos

Repositorio con una serie de notebooks de práctica para introducirse en la librería NumPy y trabajar con arreglos (arrays), sus atributos y operaciones básicas.

> Nota: aunque el nombre del repositorio menciona Pandas, el contenido de los archivos se centra principalmente en NumPy.

## Descripción

Este repositorio contiene ejercicios y ejemplos para aprender los fundamentos de NumPy, una de las librerías más importantes de Python para el manejo de estructuras de datos numéricas.

Se abordan temas como:

- creación de arrays
- arrays multidimensionales
- atributos de los arrays
- indexación y slicing
- manipulación de datos numéricos
- resolución de ejercicios prácticos

## Contenido del repositorio

### 1. Atributos de los Arrays_adaptado.ipynb
Notebook introductorio donde se exploran atributos clave de un array como:

- shape
- size
- ndim
- dtype

Se incluye un ejemplo práctico con ventas trimestrales para mostrar cómo trabajar con arrays unidimensionales.

### 2. Creación_de_Arrays_Multidimensionales_.ipynb
Notebook centrado en la creación de arrays multidimensionales y en la estructura de datos matriciales. Aquí se revisan conceptos como:

- arrays 1D y 2D
- uso de np.array()
- organización de datos en filas y columnas
- manipulación de matrices

### 3. Indexación_y_Slicing.ipynb
Archivo dedicado a la selección y acceso a elementos dentro de un array:

- acceso por posición
- slicing
- selección de rangos
- indexación avanzada
- manipulación de subarrays

### 4. Mision_Práctica_El_Tablero_de_Ajedrez.ipynb
Ejercicio práctico y más aplicado, en el que se trabaja con una representación del tablero de ajedrez usando arreglos. Este tipo de actividad ayuda a reforzar la lógica con NumPy en un contexto creativo.

## Objetivos de aprendizaje

- Comprender qué es un array en NumPy.
- Crear y manipular arrays de una o varias dimensiones.
- Conocer los atributos básicos de un array.
- Usar indexación y slicing de forma eficiente.
- Aplicar NumPy en ejercicios prácticos.

## Requisitos

- Python 3.x
- Jupyter Notebook o Jupyter Lab
- NumPy
